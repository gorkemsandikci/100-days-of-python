# Day #2 - Tip Calculator

## What it does
Asks the user for the total bill, tip percentage, and number of people, then calculates how much each person should pay.

## How to run
```bash
python main.py
```

## What I learned
- How to use `float()` and `int()` to convert `input()` strings to numbers
- How to format numbers with `:.2f` inside f-strings
- English variable naming conventions in Python
- The difference between tip amount and total, and how to split correctly

## What was hard
- I mistakenly divided only the tip amount by the number of people instead of dividing the total bill
