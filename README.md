# 100 Days of Python

100 days, one Python project a day, from **20 Oct 2026** to **27 Jan 2027**. The program goes from the
basics to OOP and testing, automation and APIs, data and machine learning, and web apps with local LLMs.
It is the sequel to [100 Days of JavaScript](https://gorkemnet.com/challenges/js/)
([repo](https://github.com/gorkemsandikci/100days100projects)).

Every line of code here is written by me. See the rules below.

# Rules

- **One project a day.** Each day has its own folder (`001-Greeting-Card`) and is committed and pushed before 11:59 PM (Istanbul time).
- **The calendar decides the day.** Day N is the date in the table below. A missed day stays missed: it is done later and marked ⏰ late, and the next day does not move.
- **I write the code myself.** No code generated by AI tools and no copy-pasted solutions. I can read documentation, books and articles, and after 30 minutes of being stuck I can ask for an *explanation of a concept*, never for the solution.
- **AI is a teacher/mentor, not a code generator.** When asking the AI assistant, its job is to explain concepts, guide with hints, review my thought process, and teach—never to write the solution or project code for me.
- **Every project has a README:** what it does, how to run it, what I learned and what was hard (template in [`_template/README.md`](_template/README.md)).
- **Must-have first, stretch later.** The day's goal in [PROGRAM.md](PROGRAM.md) must work; stretch goals are optional.
- **Tests from day 31.** From day 31 every project has at least one pytest test.
- **Standard library first.** A third-party package is used only when the day's topic needs it, and is pinned in the project's `requirements.txt`.
- **Every 20th day is a milestone** that combines the block's topics in one bigger project.
- **Share the progress** on GitHub and LinkedIn with **#100DaysOfPython**, at least once a week.
- **Missed day = $5** to a box that goes to stray animals at the end of the 100 days (kept from the JavaScript challenge).

# Repository layout

```
001-Greeting-Card/
  README.md          what, how to run, what I learned
  main.py
  requirements.txt   only if the project needs packages
  tests/             from day 31
_template/README.md  copy this for each day
```

Run a project:

```bash
cd 001-Greeting-Card
python -m venv .venv && .venv\Scripts\activate   # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt                    # if present
python main.py
```
